## 로고 6차 (최종 후보) — b·a·n 얼굴 (BANB-22 6차)

5차 피드백: 5-3(b·n 윙크)이 좋다 → "ban"이 되도록 **a도 넣기.** 5-3의 윙크와 4-1의 반쪽 동전 주머니 유지, 복잡하지 않게, 16px는 단순화본 허용.

- 보드: `../img/board-logos-v6.png` · 실제 16px(1배 렌더 8배 확대): `../img/favicon16-v6-x8.png`
- 원본: 이 폴더. 시안마다 원본 3개(`logo-*.svg`, `-dark`, `-appicon`) + **16px 단순화본 3개**(`-16.svg`, `-16-dark`, `-16-appicon`)
- 글자는 도형으로 그렸다(글꼴 필요 없음). 눈·코·입은 SVG mask 구멍.

| 시안 | 얼굴 | 한 줄 컨셉 |
|---|---|---|
| 6-1 b·a·n 한 줄 | b 눈 · a 코 · n 윙크가 가로로 "b a n" + u 입 | 글자 순서가 그대로 읽힘. 대신 요소가 4개라 가장 빽빽함 |
| 6-2 b·n 눈 + a 입 | b 눈, n 윙크, 그 아래 a가 크게 웃는 입 | 요소 3개로 가장 단순. 위에서 아래로 "b a n" 삼각형 |
| 6-3 6-2 짙은 초록 | 6-2와 같음 | 더 짙은 초록 `#1E6B4F`, 앱 아이콘은 초록 바탕에 흰 주머니 |

16px 단순화본(`-16.svg`): 획을 4.2 → 5.6으로 굵게, b 눈 → 동그란 점 눈, a 코 → 점, a 입 → 동그랗게 벌린 입. n 윙크는 그대로. 실제 16px에서 원본은 글자가 뭉개지지만, 단순화본은 "점 눈 + 윙크 + 웃는 입 + 금색 동전"으로 또렷하다. 파비콘(16px)과 탭 아이콘에는 단순화본, 32px 이상에는 원본을 쓴다.
16px 확인 이미지의 다섯 번째(앱 아이콘을 16px로 줄인 것)는 흰 주머니가 바탕과 붙어 약하다 — 앱 아이콘은 48px 이상에서만 쓰므로 문제는 없다.
독창성: 눈으로만 점검했고 상표 검색은 하지 않았다. 확정하면 KIPRIS 도형 검색을 권한다.
