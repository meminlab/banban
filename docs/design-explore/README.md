## 디자인 탐색: 스타일 샘플 4종 + 로고 시안 5종 (BANB-22)

방향을 고르기 위한 **비교용 자료**다. 고른 안은 디자인 시스템 v1.2(`docs/design.md`)에 반영한 뒤 화면 시안(BANB-19)을 다시 시작한다. 여기 있는 파일은 앱 코드에 쓰지 않는다.

- 비교 보드: `img/board-samples.png` (샘플 4종), `img/board-logos.png` (로고 5종)
- 원본: `samples/*.html` (360px 정적 목업), `logos/*.svg`, `logos/board.html`
- HTML은 브라우저로 바로 열 수 있다. 글꼴·아이콘은 미리보기용 CDN으로 불러온다(인터넷 필요).

### 1. 스타일 샘플 (안마다 다른 색감)

같은 더미 데이터(2026년 11월, 민지·준호, 수입 5,620,000 / 지출 2,835,500 / 저축 1,500,000 / 남은 돈 1,284,500)로 **홈 + 내역 입력** 2화면씩 만들었다.

| 안 | 한 줄 컨셉 | 포인트 색 | 글꼴 | 특징 |
|---|---|---|---|---|
| A. v1.1 변주 | 확정된 v1.1 구조 그대로, 포인트 색만 바꾼 안 | 베리 `#A23B72` | Pretendard | 회색 바탕 + 흰 카드, 무채색 중심. 지금 코드에 옮기기 가장 쉽다 |
| B. 핀테크 클린 | 흰 바탕 맨 위에 "이번 달 쓴 돈" 큰 숫자, 은행 앱 같은 정돈감 | 초록 `#00875A` (농도 4단계) | Pretendard | 카드 대신 회색 띠로 구역 구분. 입력은 **키패드 먼저**(숫자부터 누르고 나머지는 요약 행) |
| C. 따뜻한 커플 | 두 사람 얼굴이 늘 보이는 "우리" 가계부 | 코랄 `#C44536` + 버터 `#F6D98B` | Pretendard + 고운돋움(제목) | 큰 라운드, 사람별 색, 주머니 목표 한 줄 안내. 입력 문구가 말 걸듯 ("오늘 어디에 썼어요?") |
| D. 그래픽 감성 | 컬러 블록과 굵은 타이포의 포스터 같은 화면 | 코발트 `#2335D9` + 라임 `#E4FF3A` + 핑크 | Pretendard + Space Grotesk(숫자·영문) | 카테고리 비율을 색 블록 크기로. 입력은 어두운 화면에 큰 라임 숫자 |

공통으로 지킨 것: 금액은 `tabular-nums` 천 단위 구분, 지출은 무채색, 수입·저축은 금액 숫자에만 의미 색, 아이콘은 Lucide 1종, 글자 대비 WCAG AA(포인트 색 위 흰 글자 4.9 이상, D의 라임 위 검정 16.5).

안별로 v1.2에서 정해야 할 점:
- A: 의미 색(수입 남색·저축 청록)은 v1.1 그대로라 바로 쓸 수 있다.
- B: 포인트 색이 초록이라 **저축 금액 색과 겹친다** → 고르면 저축 색을 바꿔야 한다(예: 청록 → 차분한 보라).
- C: 사람별 색(살구·버터)이 생기므로 **4명까지 쓸 사람 색 4개**를 정해야 한다. 홈 요약은 "562만"처럼 만 단위 축약을 썼는데, 정확한 금액을 어디서 보여줄지 정해야 한다.
- D: 다크 입력 화면·영문 라벨(AMOUNT, 11.06 FRI)은 연출이다. 실제 적용 때는 한글 라벨로 바꾸고, 라이트/다크 체계를 새로 짜야 해서 **작업량이 가장 크다**.

### 2. 로고 시안 5종

모두 **심볼 중심**이고 "반반" 글자를 쓰지 않았다. 심볼은 도형만으로 그려서 글꼴이 필요 없다. 워드마크(`banban`)는 보드에서 Pretendard 800(OFL)으로 보여준 것이며, 확정하면 윤곽선(path)으로 바꾼다.

| 시안 | 한 줄 컨셉 | 색 |
|---|---|---|
| 1. 반쪽 동전 | 두 반쪽이 맞물려 동전 하나. 살짝 어긋난 높이로 "합치는 중" | 짙은 초록 + 민트 |
| 2. 두 잎 새싹 | 한 줄기에서 난 두 잎. 둘이 같이 키우는 돈 | 올리브 + 연두 |
| 3. 반반 주머니 | 반으로 나뉜 주머니에 동전이 떨어지는 순간. 앱의 "주머니"와 연결 | 코랄 + 살구 + 머스터드 |
| 4. 반 접은 종이 | 대각선으로 반 접힌 타일. 가장 기하학적이고 작은 크기에 강함 | 코발트 + 탠저린 (앱 아이콘은 코발트 + 라임) |
| 5. 둘이 한 그릇 | 두 사람(점)이 하나의 그릇(곡선)을 함께 채움. 가장 다정한 인상 | 베리 + 앰버 |

시안마다 파일 3개: `logo-N-이름.svg`(밝은 바탕), `-dark.svg`(어두운 바탕), `-appicon.svg`(정사각 라운드 앱 아이콘). 보드에서 96·48px 앱 아이콘, 32·16px 파비콘 크기로 확인했다.

독창성: 눈으로 본 자체 점검만 했고 **상표 검색은 하지 않았다.** 2(새싹)·5(두 점 + 곡선)는 흔한 모티프라 비슷한 로고가 있을 수 있다. 확정 후보는 KIPRIS(특허정보검색서비스) 도형 상표 검색으로 한 번 더 확인하는 것을 권한다.

## 로고 2차 시안 6종 — 가계부 느낌 (BANB-22 2차)

클라이언트 피드백: 1차 후보 1(반쪽 동전)·3(반반 주머니)·5(둘이 한 그릇)이 좋지만 **가계부 느낌이 약하다.** 세 개를 장부·영수증·원화·계산 모티프로 각 2가지씩 바꿨다.

- 보드: `img/board-logos-v2.png` · 원본: `logos-v2/*.svg`, `logos-v2/board.html`
- 시안마다 밝은 바탕용·`-dark`·`-appicon` SVG 3개. 심볼은 도형만(글꼴 필요 없음), 구멍은 SVG mask라 어떤 바탕에서도 비친다.

| 시안 | 1차 | 가계부 모티프 | 한 줄 컨셉 | 색 |
|---|---|---|---|---|
| 1a. 장부 동전 | 1 | 장부 줄 | 반쪽은 동전, 반쪽은 줄 친 장부. "돈 + 기록" | 짙은 초록 + 민트 |
| 1b. 같은 몫 동전 | 1 | 원화(₩)·등호 | 두 줄이 동전을 가로질러 = (똑같이 반반)이자 ₩의 두 획 | 남색 + 금색 |
| 3a. 영수증 주머니 | 3 | 영수증 | 반반 주머니에 영수증이 꽂힌 순간 | 코랄 + 살구 + 머스터드 |
| 3b. 장부 주머니 | 3 | 줄 노트 | 주머니 반쪽이 줄 노트, 동전이 장부로 들어감 | 짙은 청록 + 민트 + 주황 |
| 5a. 영수증 친구 | 5 | 영수증 | 웃는 영수증. 두 눈 = 두 사람(색이 다름) | 베리 + 앰버 |
| 5b. 하나 더하기 하나 | 5 | 계산(+) | 두 사람 + 더하기 = 한 그릇 | 베리·앰버 + 보라 |

작은 크기: 16px 파비콘에서 1a·3b의 장부 줄은 1px 정도로 뭉개져 "반쪽 동전/주머니"로만 읽힌다. 16px에서도 모티프가 남는 건 1b(두 줄)·5a(영수증 톱니)·5b(+). 확정하면 16px 전용 단순화본(줄 2개로 줄이기 등)을 따로 만든다.
독창성: 눈으로만 점검했고 상표 검색은 안 했다. 1b는 "가로줄이 그어진 원"이라 비슷한 기업 로고가 있을 수 있어, 확정 후보가 되면 KIPRIS 도형 검색을 권한다.
