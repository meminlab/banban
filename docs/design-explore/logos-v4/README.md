## 로고 4차 시안 4종 (BANB-22 4차)

3차 피드백: 얼굴이 가운데서 쪼개져 무섭고 선인장 같다 → **얼굴은 쪼개지 않는다.** 동전 두 개는 삐에로 같다 → 5a의 귀여움 유지.

- 보드: `../img/board-logos-v4.png` · 원본: 이 폴더의 SVG(밝은 바탕용·`-dark`·`-appicon`), `board.html`
- 공통: 매끈한 몸통 하나 + 5a식 웃는 얼굴(두 눈 = 두 사람, 눈·입은 SVG mask 구멍). 글꼴 필요 없음.

| 시안 | 방향 | 한 줄 컨셉 | 색 |
|---|---|---|---|
| 4-1 반쪽 동전 주머니 | 1 돈을 쪼개 넣는다 | 웃는 주머니에 반으로 나뉜 동전 **한 닢**이 들어감. 각자 반씩 넣어 함께 모은다 | 클린 초록 `#007F55` + 금색 두 톤 |
| 4-2 반반 영수증 주머니 | 1 | 웃는 주머니에 두 톤으로 나뉜 영수증이 꽂힘. 같이 쓰고 같이 기록한다 | 같은 초록 + 금색 두 톤 |
| 4-3 두 톤 복주머니 | 2 색으로만 반반 | 둥근 복주머니 하나를 짙은 초록·민트로만 나눔. 틈·절단선 없음 | 초록 두 톤 + 금색 매듭 |
| 4-4 4-1 코랄 | — | 4-1과 같은 모양, 다른 색 | 포근 코랄 `#C44536` |

작은 크기: 16px 파비콘에서 웃는 얼굴은 4종 모두 남는다. 4-1의 반쪽 동전은 "두 톤 점"으로, 4-2의 영수증 톱니는 네모로 뭉개진다. 4-3은 두 톤 경계가 16px에서도 보인다.
4-3의 매듭은 작은 크기에서 왕관처럼 보일 수 있다. 고르시면 매듭을 끈 한 줄로 단순화해 시험한다.
독창성: 눈으로만 점검했고 상표 검색은 하지 않았다. "웃는 주머니·돈주머니" 모티프는 흔한 편이라 확정 후보는 KIPRIS 도형 검색을 권한다.
