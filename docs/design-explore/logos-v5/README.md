## 로고 5차 시안 4종 — banban 글자로 만든 얼굴 (BANB-22 5차)

4차 피드백: 4-1(반쪽 동전 주머니)이 기본 뼈대. 4-3은 흔한 스마일 같아 개성이 약함 → **얼굴 표정을 banban 글자로.**

- 보드: `../img/board-logos-v5.png` · 실제 16px 확인(1배 렌더를 8배 확대): `../img/favicon16-v5-x8.png`
- 원본: 이 폴더의 SVG(밝은 바탕용·`-dark`·`-appicon`), `board.html`
- 뼈대: 4-1과 같은 주머니 하나 + 반으로 나뉜 동전 한 닢. 눈·입은 **글자 획을 도형으로 그린 것**(글꼴 필요 없음, 획 굵기 4.2/64)이고 SVG mask 구멍이다.

| 시안 | 눈 | 입 | 한 줄 컨셉 | 색 |
|---|---|---|---|---|
| 5-1 b·d 눈 | `b` `d` (볼록한 쪽이 서로 마주 봄) | `u` (뒤집은 n) | 둘이 마주 보는 부부 | 클린 초록 |
| 5-2 n·n 눈 | `n` `n` (눈웃음 ∩∩) | `u` | banban의 n으로 만든 웃는 눈 | 클린 초록 |
| 5-3 b·n 윙크 | `b` (뜬 눈) + `n` (윙크) | `u` | 장난스러운 표정 | 클린 초록 |
| 5-4 5-2 코랄 | 5-2와 같음 | | 다른 색 안 | 포근 코랄 |

16px 확인 결과(정직하게): 실제 16px(1배)에서는 **글자 모양까지는 읽히지 않고 "웃는 주머니 + 금색 동전"으로 보인다.** 표정은 남는다. 글자가 읽히기 시작하는 건 32px부터. 그래서 확정하면 16px 파비콘 전용본을 따로 만든다: 획을 굵게(5.5), n 눈은 그대로, b·d 눈은 볼록한 부분만 남긴 점 눈으로 단순화.
독창성: 눈으로만 점검했고 상표 검색은 하지 않았다.
