## 로고 3차 시안 4종 (BANB-22 3차)

클라이언트 피드백(2차): 1a의 단순한 실루엣 + 3a·3b의 "주머니에 영수증·동전이 들어간다"(모으고 기록한다) + 5a의 웃는 얼굴(두 눈 = 두 사람)을 합쳐 달라.

- 보드: `../img/board-logos-v3.png` · 원본: 이 폴더의 SVG(밝은 바탕용·`-dark`·`-appicon`), `board.html`
- 공통: 반으로 나뉜 몸통(가운데 틈 = 반반), **반쪽마다 눈 하나**(한 사람씩), 두 반쪽에 걸친 하나의 웃는 입. 눈·입은 SVG mask 구멍이라 어떤 바탕에서도 비친다. 글꼴 필요 없음.

| 시안 | 한 줄 컨셉 | 가져온 것 | 색 |
|---|---|---|---|
| 3-1 둥근 반반 주머니 | 동그란 반반 몸통 위로 영수증이 살짝 보임 | 1a 실루엣 + 영수증 + 얼굴 | 클린 초록 `#007F55` + 민트 + 머스터드 |
| 3-2 영수증 꽂힌 반반 주머니 | 반반 주머니에 영수증이 꽂히고 주머니가 웃음 | 3a + 얼굴 | 같은 초록 |
| 3-3 동전 넣는 반반 주머니 | 반반 주머니로 동전이 떨어지고 주머니가 웃음 | 3b + 얼굴 | 같은 초록 |
| 3-4 3-2 코랄 | 3-2와 같은 모양, 다른 색 | — | 포근 코랄 `#C44536` + 살구 |

작은 크기: 16px 파비콘에서도 두 눈과 웃는 입은 보인다. 3-1·3-2의 영수증 톱니는 16px에서 직사각형으로 뭉개지고, 3-3의 동전은 점 하나로 남는다.
가운데 틈이 입을 둘로 나눈다: "둘이 각자 반쪽씩, 같이 웃는다"는 뜻으로 일부러 남겼다. 고르신 안을 다듬을 때 틈을 입 아래에서만 끊는 방식도 시험할 수 있다.
독창성: 눈으로만 점검했고 상표 검색은 하지 않았다. 확정 후보는 KIPRIS 도형 검색을 권한다.
