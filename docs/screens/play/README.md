## 같이 놀기 (오목 1차) 시안 (BANB-48)

기준은 BANB-2 "미니게임 '같이 놀기' 명세"(클라이언트 승인 2026-11-09)다. 규칙은 `docs/design.md` v1.7(1.7, 5.28~5.31)에 있고, 이 폴더에는 그림을 모았다.

- `play.html`: 클린 라이트 360×760 화면과 오목 판 클린 다크 1장. 주소 끝에 `?s=home|invite|pick|room|board|state|result|dark`를 붙이면 그 줄만 보인다. `&bare`를 더하면 제목을 숨긴다.
- `img/play-*.png`: 줄별 스크린샷 8장.
- 샘플은 멤버 민지(멤버 1, 하늘)와 준호(멤버 2, 노랑)다. 따로 적지 않은 화면은 민지 폰이다. 민지가 초대했으므로 준호가 흑(먼저), 민지가 백이다.
- 새 토큰은 게임 색 5개(`game-board`, `game-line`, `stone-black`, `stone-white`, `stone-edge`)뿐이다. 모두 테마 공통이고 라이트/다크 값이 있다. 나머지는 v1.6 토큰을 그대로 쓴다.

### 기획·개발 확인 필요

1. **초대 취소**: 명세에는 없다. 시안은 대기실에 "초대 취소" 버튼을 넣었다(추천: 넣기). 넣으면 `game.status`를 `declined`로 둘지, 새 값으로 둘지 정해야 한다.
2. **중단(`abandoned`) 판의 전적**: 시안은 전적에 넣지 않는다(승자가 없음).
3. **자리 비움 판정 기준**: 시안은 Realtime presence가 끊긴 상태를 "앱을 나감"으로 본다. 몇 초 뒤에 표시할지는 개발이 정한다(추천: 10초, 깜빡임 방지).
4. 판 크기: 430px 폭에서는 판이 400까지 커진다(줄 간격 약 27px). 그래도 누르고 확인하는 2단계 방식은 똑같이 쓴다.
