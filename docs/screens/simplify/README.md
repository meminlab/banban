## UI 단순화 제안 — 전/후 (BANB-35)

클라이언트 피드백(BANB-2 3번 "UI가 조금 복잡함")에 대한 **제안**이다. 클라이언트 확정 전에는 개발하지 않는다.

- 전: 지금 운영 화면과 같은 v1.2 시안(`../assets-home.html` H1·A1, `../screens.html` B1·E1·T1) 캡처. 운영 코드의 문구·구성과 일치하는지 대조했다.
- 후: `simplify.html` (클린 라이트, 360×760). 새 토큰은 없다(v1.2 토큰만 씀).
- 그림: `pair-*.png` = 전 · 후 · 덜어낸 것 한 장, `before-*.png` / `after-*.png` = 각 화면 한 장.

### 공통 규칙 (제약 3개 적용 방식)
1. **강조 색 1개 = 테마 primary.** 수입 금액만 primary, 지출·저축은 기본 글자색(지출은 `−`, 수입은 `+`, 저축은 부호 없음). 전월 대비 파랑·저축 보라는 쓰지 않는다. 빨강(`negative`)은 오류·음수 순자산에만.
2. **카드 안 정보 3줄 이내.** 기본형 = 제목 / 큰 숫자 / 한 줄 요약.
3. **라벨·구분선·보조 문구 제거.** 값만 보고 알 수 있는 라벨(카테고리·주머니·쓴 사람·날짜), 묶음 제목, 계산식·안내 문장은 뺀다. 묶음 구분은 여백으로만.

### 화면별 덜어낸 것

**1. 홈** (`pair-home.png`)
- 헤더 가계부 칩의 멤버 머리글자(민·준)
- 월 이동 카드 → 카드 없는 한 줄, 올해는 연도 생략("11월")
- 순자산 카드의 작은 추이 그래프 → 자산 탭 "6개월 추이"에 있음
- "남은 돈 = 수입 − 지출 − 저축" 문구, 수입·지출·저축 3칸 머리말 → 한 줄 요약
- "누가 얼마나 썼나" → "누가 썼나" + 이름·금액 한 줄(막대만 있어 읽기 어려웠던 부분 보완)

**2. 가계부** (`pair-ledger.png`)
- 목록|달력 세그먼트·필터 버튼 → 월 줄 오른쪽 아이콘 2개
- 이달 지출·수입·저축 3칸 → 홈 "남은 돈" 카드에만 (중복 제거)
- 내역 보조 줄의 주머니 이름, "저축"·"고정" 배지 → 보조 줄은 "카테고리 · 사람"만 (저축은 카테고리 자리에 "저축")
- 날짜 머리의 "지출 없음" 문구, 날짜별 합계는 흐린 글자로

**3. 내역 입력** (`pair-entry.png`)
- "내역 입력" 제목 → 지출/수입/저축 세그먼트가 제목 자리로
- "얼마를 썼나요?" 질문, 한글 금액 읽기 줄
- +1천·+1만·+5만·+10만 빠른 금액 칩
- 카테고리·주머니·쓴 사람·날짜 4줄 표(라벨+구분선) → 라벨 없는 알약, 누르면 지금과 같은 시트
- "+ 메모 추가" 줄 → 알약 줄 끝의 "+ 메모"

**4. 자산** (`pair-assets.png`)
- 월초 안내 상자의 아이콘·보조 문구 → "11월 잔액 확인하기 ›" 한 줄
- 순자산 카드의 전월 대비·구분선·총자산/총부채 2칸 → "자산 · 부채" 한 줄 (전월 대비는 추이 카드 제목 줄로)
- 월별 추이의 "월말 순자산"·"11월 (지금) 금액" 캡션, 점 6개·월 이름 6개 → 선 하나 + 처음·끝 달
- 자산 구성 7줄(막대·금액·%)과 부채 합계 → 쌓인 막대 1개 + 종류 한 줄
- 자산 행의 "3일 전 수정" 보조 문구

**5. 설정** (`pair-settings.png`)
- 묶음 제목(가계부 / 지금 보는 가계부: 이름 / 내 설정 / 계정)
- 개수 표시(2개·2명·43개·4개) — 값이 설정 자체인 이름·테마만 남김
- 줄 이름 줄임: "이 가계부에서 내 이름"→"내 이름", "카테고리 관리"→"카테고리", "주머니 관리"→"주머니"
- 계정 줄의 아바타·"구글 계정" 문구·테두리 버튼 → 메일 + 글자 버튼 "로그아웃"
- "가계부 관리"를 맨 위에서 화면 테마 옆으로(자주 안 씀)

### ⚠️ 덜어내서 사라지거나 옮겨지는 기능

| 무엇 | 어디로 | 비고 |
|---|---|---|
| 빠른 금액 칩(+1천~+10만) | **없어짐** (키패드 `00`으로 입력) | 살리려면 키패드 위 한 줄로 되돌리기 가능 — 확정 질문 2 |
| 한글 금액 읽기("만 이천팔백 원") | **없어짐** | 큰 금액 오입력 방지용이었음. 100만 원 이상일 때만 보이기도 가능 — 확정 질문 2 |
| 가계부 탭 이달 합계 3칸 | 홈 "남은 돈" 카드 한 줄 | 필터 걸었을 때 합계는 필터 시트 "N건 보기"에 금액 추가로 보완(개발 시) |
| 내역 행의 주머니·고정 배지 | 내역 수정 화면, 필터 | 정보는 그대로 저장됨 |
| 자산 구성의 종류별 금액·% | 막대 1개 + 자산 목록 | 종류별 금액이 필요하면 구성 카드를 눌러 펼치기 — 확정 질문 3 |
| 홈 순자산 작은 그래프 | 자산 탭 "6개월 추이" | |
| 설정 개수 표시 | 각 하위 화면 | |

### 확정해 주실 것 (선택지 · 추천)
1. 금액 색: ① 수입만 primary(추천, 제약 1 준수) ② 지금처럼 수입 파랑·저축 보라 유지(제약 1 예외)
2. 입력 화면: ① 칩·한글 읽기 모두 제거(추천) ② 한글 읽기만 100만 원 이상일 때 보이기 ③ 둘 다 유지
3. 자산 구성: ① 막대 1개 + 한 줄(추천) ② 눌러서 펼치면 지금의 7줄

확정되면 `design.md`의 금액 색·카드 규칙을 고치고(다크 토큰 BANB-33과 겹치지 않게 그 뒤에), 기획이 개발 이슈를 만든다.
