## 화면 시안 (BANB-19)

기준은 디자인 시스템 v1.2(`docs/design.md`)이고, 화면 폭은 360px(높이 760)이다. 색·글자·간격은 v1.2 토큰만 쓴다.

| 파일 | 담은 화면 |
|---|---|
| `assets-home.html` | 홈, 자산 탭, 자산 입력·보관 (BANB-22에서 먼저 확정) |
| `screens.html` | 로그인, 시작, 가계부 탭, 내역 입력·수정, 설정(테마·멤버·카테고리·주머니), 가계부 관리 |
| `../design-preview-flows.html` | 가계부 전환 시트, 카테고리 선택·추가 동선 (v1.2) |
| `img/screens-*.png` | `screens.html`의 줄별 스크린샷 (1~10) |

- `screens.html` 주소 끝에 `?r=0`~`?r=8` 또는 `?r=themes`를 붙이면 그 줄만 보인다.
- 시안의 내역·금액·주머니 값은 샘플 가계부(BANB-23 `supabase/seed/sample_ledger.sql`)의 2026년 11월 1~6일 데이터다. 사람 이름(민지·준호)은 홈·자산 시안과 맞춘 표시용 이름이다.
- 로고는 BANB-22 확정안 **B-1 웃는 주머니**(가로 조합, 높이 44)를 넣었다. 원본·규칙은 `docs/brand/`. 로고 색은 테마와 상관없이 고정이고, 다크에서는 다크용 색.

### 화면별 바뀌는 점과 개발 주의점

**1. 로그인 (L1~L4)**
- 바뀌는 점: 큰 제목 두 줄 아래에 앱 화면 맛보기 카드(정적 그림)를 넣고, 구글 버튼을 아래쪽에 고정했다. 문구는 "구글 계정으로 시작하기"로 바꾼다.
- 주의: 맛보기 카드는 장식이다(`aria-hidden`, 실제 데이터 아님). 카카오톡 인앱 안내는 실패 상자와 따로 회색 안내 상자로 보여 준다. 로고는 BANB-22 확정본(B-1) 반영 완료.

**2. 시작·만들기·초대코드 (S1~S5)**
- 바뀌는 점: 가계부가 0개일 때 두 갈래 큰 카드를 보여 준다. 아이콘(BookPlus·Ticket)은 전환 시트의 "가계부 추가" 카드와 같게 맞췄다. 만들기와 참여는 각각 하위 화면이고, 아래 고정 버튼을 쓴다.
- 주의: 초대 코드는 4자씩 띄워 보여 주지만 값은 8자다. 붙여넣기할 때 공백·하이픈을 지운다. 5개 상한 오류에는 갈 곳(설정 › 가계부 관리)을 함께 알려 준다. "가계부에서 쓸 내 이름" 칸은 지금 앱에 있으면 그대로 두고, 없으면 이 화면에서는 빼도 된다(구현 판단).

**3. 가계부 탭 (B1~B7)**
- 바뀌는 점:
  - 월 이동 줄을 홈과 같은 자리(카드 밖 맨 위)로 옮겼다.
  - 그 아래 도구 카드에 [목록|달력] 세그먼트, 필터 버튼, 이달 지출·수입·저축 3칸을 넣었다.
  - 날짜 머리를 날짜 카드 안으로 넣었다. 클린 테마는 카드가 화면 끝까지 닿기 때문이다.
- 주의:
  - 저축만 있는 날의 날짜 머리 오른쪽에는 "지출 없음"이라고 쓴다.
  - 달력 칸 금액은 만 단위(`compactWon`)로 쓴다.
  - 필터 칩은 누르는 즉시 걸린다(지금 동작 유지). 시트 아래 "N건 보기" 버튼은 결과 수를 보여 주는 닫기 버튼이다.
  - 내역 행 제목·보조 줄은 한 줄 말줄임이다(자산 행은 줄바꿈이라 서로 다르다).

**4. 내역 입력·수정 (E1~E9)**: `design.md` 5.15를 그대로 화면에 옮겼다.
- 높이 배분(360×760): 키패드 키 높이 44, 저장 버튼 52.
- 버튼 위에 오류·안내 문장이 붙으면 한글 금액 읽기 줄을 숨겨서 키패드가 메모 줄을 가리지 않게 한다.
- 수입·저축에는 주머니 행이 없다. 사람 행 이름은 받은 사람 / 모은 사람으로 바뀐다.
- 고정지출 체크는 날짜 시트 안에 있고, 켜면 날짜 행에 "고정" 배지가 붙는다.
- 메모는 한 줄 시트에서 쓴다(100자, 글자 수 표시).
- 삭제 확인 창의 첫 포커스는 취소다.

**5. 설정 (T1~T4)**
- 바뀌는 점: 묶음 순서를 "가계부(가계부 관리)" → "지금 보는 가계부: 이름"(이름·내 이름·멤버·카테고리·주머니) → "내 설정(화면 테마)" → "계정"으로 정했다(5.18). 계정 행은 한 줄로 줄이고, 오른쪽에 보조 버튼 "로그아웃"을 둔다.
- 주의: "지금 보는 가계부" 묶음 제목의 이름은 한 줄 말줄임이다. 화면 테마(T2)는 5.16 그대로 개발하되 별도 이슈로 진행한다. 누르면 즉시 적용되고 사용자별로 저장된다.

**6. 카테고리·주머니 (T5~T8)**
- 카테고리 관리: 종류 세그먼트 아래에 대분류 목록(아이콘 원 + 소분류 이름 나열)을 둔다. 숨긴 항목은 흐린 글자에 "숨김" 배지를 붙이고, 직접 만든 대분류에 아이콘이 없으면 첫 글자를 쓴다.
- 카테고리 추가(T6)는 5.17 그대로다. 아이콘 저장은 BANB-24(`category.icon`)와 함께 개발한다.
- 주머니는 공동·개인을 아이콘과 글자로 함께 구분한다. 이름 20자를 넘으면 입력 아래에 오류를 보여 주고 추가 버튼을 비활성으로 둔다.

**7. 가계부 관리 (G1~G5)**: 5.18 그대로다.
- 5개가 차면 추가 버튼을 비활성으로 두고 이유를 한 줄 보여 준다.
- 상세 화면에서는 "이 가계부로 전환"을 주 버튼으로 두고, 나가기는 위험 글자 행으로 둔다.
- 마지막 멤버가 나갈 때는 확인 창 문구를 바꾼다(지금 앱 문구 유지).

### 결정 기록 (디자인, 2026-11-06)
- **달력에서 저축 표시**: 저축이 있는 날은 날짜 아래에 5px 점(`saving` 색)을 찍고, 범례에 "● 저축"을 둔다. 저축만 있는 날도 칸이 비어 보이지 않는다. 금액 대신 점을 쓰는 이유는 칸 폭(약 46px)에 지출·수입 금액이 이미 두 줄이라서다. 정확한 금액은 아래 선택한 날 목록에서 본다. 점은 장식이라 대비 기준에서 빼고, 칸 `aria-label`에 "저축 60만 원"을 넣는다.
- **가계부 탭 이달 합계**: 도구 카드 안에 지출·수입·저축 3칸을 둔다. 남은 돈은 홈에만 둔다. 가계부 탭은 "기록을 보는 곳"이라 계산 결과를 겹쳐 보여 주지 않는다.
- **날짜 머리는 카드 안**: 클린 테마(카드 좌우 여백 0)에서도 같은 구조로 보이게 하려는 것이다.

### 개발 반영 묶음 제안 (기획 판단용)
1. **공통 뼈대 + 테마 토큰**: `global.css` 토큰 교체, 헤더 알약, 탭바 가운데 ＋, 카드 강조 토큰. 이관된 `formatWon` `−` 변경과 `--touch` 44 / `--touch-lg` 48 변경도 여기서 처리한다.
2. **로그인·시작·만들기·참여**: L·S 화면.
3. **가계부 탭**: B 화면(달력 저축 점 포함).
4. **내역 입력 키패드**: E 화면. 카테고리 시트는 BANB-24 아이콘이 있으면 그대로 쓰고, 없으면 첫 글자로 그린다.
5. **설정·가계부 관리·멤버·주머니**: T1·T3·T4·T7·T8, G 화면.
6. **화면 테마 선택**: T2 (사용자별 저장, 별도 이슈).
7. **카테고리 아이콘**: T5·T6, BANB-24 (마이그레이션은 BANB-25와 순서 조율).
