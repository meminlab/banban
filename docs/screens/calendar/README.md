## 일정 탭 · 탭바 4개 · 홈 함께한 날 카드 · 정기 내역 시안 (BANB-41)

기준: BANB-2 "일정 캘린더 명세" + "일정 명세 보강"(클라이언트 승인 2026-11-09). 규칙은 `docs/design.md` v1.6(1.6, 5.7, 5.24~5.27)에 있고, 이 폴더는 그림이다.

- `calendar.html` — 클린 라이트 360×760 + 일정 탭 클린 다크. 주소 끝에 `?s=cal|day|form|home|recurring|settings|empty|dark`를 붙이면 그 줄만 보인다(`&bare`는 제목 숨김).
- `img/cal-*.png` — 줄별 스크린샷 8장.
- 샘플 데이터: 오늘 = 2026년 11월 9일(월), 멤버 민지(멤버 1)·준호(멤버 2). 음력 날짜는 파이썬 `korean-lunar-calendar`로 맞춰 봤다(음력 10월 3일 → 2026-11-11, 시안 확인용. 앱에서 쓸 라이브러리 선정은 개발).
- 새 토큰은 일정 색 5개(`event-together`, `event-1~4`)뿐이다. 나머지는 v1.5 토큰 그대로.

### 기획·개발 확인 필요

1. 홈 카드에 넣을 "고정 안 한 기념일"의 범위 — 시안은 **30일 안**(먼 기념일로 자리를 채우지 않게). 명세에 기간 없음.
2. 정기 내역 제안에서 체크를 끈 회차(건너뛰기) — 기억하지 않으면 30일 동안 계속 제안된다. 회차를 기록할 자리가 필요(데이터).
3. 정기 내역으로 만든 내역의 날짜 — 시안은 정기 내역 날짜(놓친 건 그 날짜)로 저장.
